# Кулінарний помічник

Android звертається лише до LeCook API. GEMINI_API_KEY зберігається в Environment
Render, не передається клієнту й не потрапляє в URL або повідомлення помилок.

- GET `/api/assistant/status`: `{ "available": true }`, якщо ключ налаштований.
- POST `/api/assistant`: `{ "message": "Чим замінити сметану?", "context": "Рецепт: сирники…" }`.
- Відповідь: `{ "answer": "…" }` українською.
- message обов’язкове, до 1500 символів; context — до 8000.
- 429 при досягненні ліміту, 503 без конфігурації, 502 при помилці провайдера.

Без GEMINI_MODEL сервер обирає доступну Flash-модель через models.list і кешує
вибір до перезапуску. GEMINI_MODEL можна явно задати в Render. Інтеграція використовує офіційний generateContent REST API
з ключем у заголовку x-goog-api-key:
https://ai.google.dev/api/generate-content.

Для прототипу: максимум два одночасні виклики, вісім викликів за хвилину та
100 за добу на весь процес. Денний ліміт змінює LECOOK_AI_DAILY_LIMIT.
Захищений GET `/api/admin/assistant/status` повертає лише назву моделі, HTTP-статус
та код останньої помилки провайдера. Ключ і тексти не повертаються.

Лічильники зберігаються в пам’яті та скидаються після перезапуску процесу.
Це обмеження прототипу, не гарантія грошового бюджету Google.

Історія розмови й контекст рецепта передаються Gemini тільки при надсиланні
запитання. LeCook не записує їх у базу й не веде журнал тіл цих запитів.
Клієнт показує джерело поради, можливість помилки та потребу інтернету.

Клієнт не надсилає адміністративний токен: цей маршрут публічний і
обмежений окремо від захищених операцій зміни каталогу.
